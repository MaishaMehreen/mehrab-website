Tips so pages stay fast:
  - 3–6 seconds each for previews, 10–20 seconds for the showreel
  - 720p (1280px wide) is plenty; aim for under 2 MB per preview, under 6 MB for the showreel
  - Remove the audio track
  - Free tool: HandBrake (handbrake.fr) → preset "Fast 720p30", tick "Web Optimized"

File names must match the "previewClip" / "loopFile" values in src/content/site.json.
Full videos with sound are NOT stored here: use YouTube (unlisted) or Vimeo IDs in site.json.
